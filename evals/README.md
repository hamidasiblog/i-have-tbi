# Evals

A minimal set of hand-checkable cases. There is no runner in this repository.

Each line of `cases.jsonl` has a `prompt` to send with the skill on, and `expect` / `reject` lists describing what a passing reply does and does not contain. Read the reply against them by hand, or adapt the runner in [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd).

These cases check the shape of the output only. They are not a clinical evaluation and say nothing about benefit to any reader.
